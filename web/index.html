SAN JOSÉ STATE UNIVERSITY · CyVerse Project

CyVerse

A browser-based, first-person cybersecurity training game. Walk a virtual security operations floor and do the work — enroll credentials, clear multi-factor authentication, triage a live alert queue, contain infected endpoints, and query real logs to solve a breach.

Play the beta Requires an access code from the project team.

Runs in the browser — no install. Desktop with a keyboard and mouse recommended.

What you'll learn

LEVEL 1

Identity & Access

Enroll an ID badge, then clear a vault using all three authentication factors — something you know, have, and are.

LEVEL 2

Cyber Defense

Work a timed SIEM alert queue, isolate compromised endpoints, and put the incident response playbook in the right order.

LEVEL 3

Digital Forensics

Investigate a phishing breach by querying security logs, pivoting from email to endpoint to attacker infrastructure.

LEVEL 4

Cyber Attack

In development — the offensive counterpart, seeing the same systems from the attacker's side.

Accessibility

  • Captions on all narration, with adjustable text size
  • Reduce Motion option that freezes animation and screen effects
  • Adjustable look sensitivity and field of view for motion comfort
  • Status shown by shape and label, never by colour alone
  • Separate master, voice and effects volume channels
Built at San José State University. Source on GitHub.
